# RF Antenna Design Projects

This repository contains MATLAB and CST Studio Suite projects developed for learning and implementing various antenna design and analysis techniques. The projects cover antenna modeling, simulation, optimization, and performance evaluation using industry-standard tools.

---

# Software Used

- MATLAB R2025a
- MATLAB Antenna Toolbox
- Global Optimization Toolbox
- CST Studio Suite Learning Edition
